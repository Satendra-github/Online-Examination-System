# 🎓 Online Examination System

An Online Examination System developed using **Python, Streamlit, and SQLite** that allows teachers to create exams and students to take them online with automatic evaluation and result management.

---

## ✨ Features

### 👨‍🏫 Teacher Module
- Teacher Login
- Question Bank Management (CRUD)
- Create Exams
- Manage Students
- Dashboard Analytics

### 👨‍🎓 Student Module
- Student Login
- View Available Exams
- Take Online Exams
- Automatic Score Calculation
- View Results
- Percentage Calculation
- Performance Feedback

---

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/Satendra-github/Online-Examination-System.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
